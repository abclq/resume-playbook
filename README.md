## 这个仓库解决什么问题

大部分人写简历的方式是：把做过的事按时间列一遍，然后润色措辞。

**这是错的。**

简历的唯一作用是：**在 6-15 秒内，让筛选者确认你和这个岗位匹配**。它不是自传，是一份「匹配度证明」。

所以这个仓库的组织方式不是「简历怎么写」，而是按真实的筛选链路倒推：

```
JD 拆解 → 关键词对齐 → 经历重写 → 自查 → 投递追踪
```

## 30 秒版

如果你只看一句话：

> **简历上的每一条，都要能回答「这跟这个岗位有什么关系」。回答不了的，删掉。**

## 核心公式

```
动作 + 对象 + 方法 + 量化结果
```

- 差：负责公司公众号运营
- 好：独立运营 3 万粉公众号，通过选题库+固定发布时间，6 个月把阅读量从 800 提升到 4200

没有数字怎么办？用**频率、规模、范围**替代：

- 每周处理 30+ 客户咨询
- 覆盖 5 个校区、2000+ 学生
- 独立负责从 0 到 1 的整个流程

## 使用方法

1. 先读 `01` 和 `02`，理解逻辑
2. 拿目标岗位的 JD，按 `02` 拆一遍
3. 用 `03` 的公式重写每条经历
4. 投递前过 `04` 的清单
5. 投了没回音，看 `05` 找原因
